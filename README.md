# سما | Sama — وكيل ذكاء اصطناعي محلي يتحكم في ويندوز

تطبيق ويندوز يعمل **بالكامل على جهازك** (بدون إنترنت أو مفاتيح API): تكتب له مهمة بالعربي، فيفكر ويستخدم أدوات
(ملفات، أوامر، فتح برامج، ماوس/كيبورد، لقطة شاشة) لتنفيذها خطوة بخطوة، مع **أمان صارم** و**سجل تدقيق**.

## التشغيل السريع (ويندوز)
انقر مرتين على **`Sama.bat`**: ينشئ البيئة ويثبّت المتطلبات وOllama والنموذج ثم يفتح التطبيق. وبعد كل push يبني GitHub Actions ملف `Sama.exe` (Actions ← build ← Artifacts).

## التشغيل اليدوي
1. ثبّت [Ollama](https://ollama.com) ثم: `ollama pull qwen2.5:7b-instruct` (أو أي نموذج أقوى يتحمله جهازك).
2. `pip install -r requirements.txt`

4. لبناء `Sama.exe`: شغّل `build.bat` على ويندوز. الاختبارات: `pip install -r requirements-dev.txt && pytest`.

الإعدادات في `%APPDATA%\Sama\config.json` (النموذج، المجلدات المسموحة، الوضع `ask`/`auto`).

## المعمارية
```
UI (نافذة pywebview + HTML)  ──HTTP محلي + توكن──►  server.py
                                                       │
                                  agent.py  (حلقة: فكّر ← أداة ← نتيجة)  ◄── llm.py (Ollama محلي)
                                       │
                         safety.py  (تصنيف + موافقة + قاطع طوارئ + تدقيق)
                                       │
                     tools.py (ملفات | PowerShell | تطبيقات | ماوس/كيبورد | شاشة | ذاكرة)
                                       │
                                  memory.py (SQLite: حقائق + تاريخ المهام)
```

## الأمان (الأساس في أي وكيل يتحكم بالجهاز)
- **ثلاثة مستويات**: آمن (قراءة فقط) ينفذ مباشرة · يحتاج موافقة منك (كتابة، أوامر، ماوس) · ممنوع نهائياً (format، shutdown، diskpart، حذف النظام...).
- الملفات محصورة في **مجلدات مسموحة** فقط (افتراضياً `~/SamaWorkspace`) ومحمية من `..`.
- انتهاء مهلة الموافقة = **رفض**. زر **⛔ إيقاف فوري** + `pyautogui.FAILSAFE` (حرّك الماوس لزاوية الشاشة).
- كل إجراء يُسجَّل في `audit.jsonl`.
- الخادم المحلي مربوط على `127.0.0.1` فقط، بتوكن عشوائي وفحص `Host`، فلا يستطيع موقع ويب التحكم بالوكيل.

## خارطة الطريق (للمستقبل)
1. **الرؤية**: نموذج متعدد الوسائط (مثل Qwen2.5-VL) يقرأ لقطة الشاشة بدل الإحداثيات العمياء.
2. **UI Automation** (`pywinauto`/UIA) للتحكم بالعناصر بالاسم لا بالإحداثيات.
3. **مهام مجدولة** ومراقبة مجلدات (تشغيل تلقائي بقواعد مسبقة الموافقة).
4. **الصوت**: Whisper محلي للأوامر الصوتية + TTS.
5. **إضافات**: واجهة Plugin لأدوات جديدة (Excel, المتصفح, البريد) كلٌّ بتصنيف أمان خاص.
6. تشغيل كخدمة ويندوز + مثبّت MSI + توقيع رقمي.

> ملاحظة: الأدوات الرسومية (ماوس/كيبورد/لقطة شاشة) لا تعمل إلا على ويندوز مع تثبيت `pyautogui`؛ بقية النظام يعمل ويُختبر على أي نظام.
