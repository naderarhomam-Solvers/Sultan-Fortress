# 02 — النيش والعرض وتصميم الخدمة

## Niche + Offer

**من نخدم:** عيادات الأسنان والتجميل والعلاج الطبيعي ومراكز العناية والصالونات الراقية (3–15 موظفًا) في الخليج وليبيا/شمال أفريقيا، تستقبل حجوزاتها عبر WhatsApp/Instagram/الهاتف.
*لماذا هذا النيش أولًا:* مواعيد = قيمة نقدية واضحة لكل حجز، الرسائل المتأخرة ضياع مباشر، والعربية ميزتك. (إن لم يستجب → صالونات، ثم مراكز تدريب، ثم عقارات.)

**المشكلة:** الرسائل خارج الدوام تضيع، الموظف يكرر نفس الإجابات، المواعيد تُنسى فتتحول إلى فراغ في الجدول.

**النتيجة التي نبيعها (لا "بوت"):**
> "خلال 14 يومًا، كل رسالة تصلكم تُرد خلال ثوانٍ بالعربية أو الإنجليزية، ويُحجز الموعد في تقويمكم تلقائيًا، وتصلكم تذكيرات تقلل الغياب — وأي حالة حساسة تُحوَّل لموظف بشري."

**اسم الخدمة:** **"مُستقبِل"** (Mustaqbil) — *موظف استقبال ذكي لا ينام* (الاسم مقترح، غيّره كما تحب).

**خطة رفع الأسعار:** بعد 3 عملاء + تقييمين موثقين → السعر العادي. بعد 10 عملاء → +30% ويصبح Pilot مغلقًا.

## كيف تُنفَّذ الخدمة (قابلة للتكرار)

1. **اكتشاف (30 دقيقة مكالمة/رسائل):** يملأ العميل `templates/client-intake.md`.
2. **ملف العميل:** Claude يحوّل الاستبيان إلى `clients/<name>/config.json` (الخدمات، الأسعار المعتمدة، ساعات العمل، الأسئلة الشائعة، قواعد التحويل، النبرة).
3. **ضبط البوت:** نفس الكود (قالب `demo/receptionist`) + ملف العميل. لا كود جديد لكل عميل.
4. **اختبار:** مجموعة 30 محادثة اختبار (أسئلة، حجوزات، شكاوى، حالات طبية، لهجات) يشغّلها Claude ويحلل الإخفاقات.
5. **مراجعة بشرية (أنت):** تقرأ 10 محادثات عينة + جميع حالات الرفض/التحويل.
6. **موافقة العميل ثم التشغيل التجريبي** 48 ساعة بوضع "اقتراح فقط" (البوت يسوّد الرد والموظف يوافق).
7. **تشغيل كامل** + تقرير الأسبوع الأول + عرض الرعاية الشهرية.

### قواعد أمان ثابتة في كل بوت
- لا نصائح طبية ولا تشخيص ولا وصف أدوية — تحويل فوري لموظف.
- لا يختلق أسعارًا أو خدمات؛ يذكر فقط ما في ملف العميل، وإلا يحوّل.
- لا يقدم التزامات مالية أو قانونية أو تخفيضات.
- يُعلم المتصل أنه مساعد آلي إن سُئل.
- لا يخزن بيانات حساسة؛ الاحتفاظ بالمحادثات محدود ومتفق عليه في العقد.
- كل ما سبق مكتوب في عقد الخدمة (قالب `templates/service-agreement.md` — مسودة تحتاج مراجعتك/قانونيًا قبل الاستخدام؛ لست محاميًا).

## Claude Code كعامل إنتاج

**ما يبنيه:** السيرفر، أدوات الحجز، التكامل مع Google Calendar/Webhooks، الاختبارات، لوحة تقارير، تقارير شهرية.
**هيكلة الملفات:**
```
freelance-ai/
  demo/receptionist/      ← القالب الأم (يُنسخ ولا يُعدَّل لكل عميل)
  clients/<client>/       ← config.json + ملاحظات + محادثات اختبار + تقارير
  templates/              ← الاستبيان، العقد، مسودات الرسائل
  kpi/                    ← المتابعة
.claude/agents/           ← الوكلاء المتخصصون (المدير يوزع عليهم)
```
**تقليل الوقت لكل مشروع:** هدف العميل الأول 15–20 ساعة، الخامس أقل من 6 ساعات، عبر: (أ) ملف config فقط لكل عميل (ب) مجموعة اختبارات ثابتة (ج) مكتبة أسئلة شائعة جاهزة لكل قطاع (د) تقارير مولدة آليًا.

**أدوات أخرى (أبسط ما يكفي):**
| الأداة | الاستخدام | التكلفة | يحتاج موافقتك؟ |
|---|---|---|---|
| Claude Code + Claude API | البناء والتشغيل | اشتراك/استهلاك | نعم (إنفاق) |
| استضافة مجانية/رخيصة (Render/Fly/VPS) | تشغيل السيرفر | $0–10 | نعم |
| WhatsApp Cloud API (Meta) | القناة | مجاني للبدء + رسوم Meta على العميل | نعم (حساب العميل) |
| Google Calendar API | المواعيد | مجاني | نعم (أذونات) |
| Upwork/LinkedIn | الوصول للعملاء | مجاني/Connects مدفوعة | نعم (Connects) |

**لا نستخدم** n8n/Make في البداية: الكود الخاص أبسط وأرخص وأكثر تحكمًا مع Claude Code. نضيفها فقط إن طلبها عميل.
